# SP Ilumina — Landing page

Site de uma página da SP Ilumina, loja de iluminação em Remanso – Bahia.
HTML, CSS e JavaScript puros, sem build. Abra `index.html` ou publique a pasta na Vercel (framework: Other).

- Produtos: lista `PRODUTOS` no final do `index.html`; fotos em `produtos/`.
- WhatsApp: constante `NUM` no final do `index.html`.
- Instagram: https://www.instagram.com/sp_ilumina/
